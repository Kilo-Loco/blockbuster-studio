How it works

  1. 1

    Deploy

    After clicking, on Runpod click a GPU card if none is selected (RTX 4090 cheapest that fits, RTX 5090 faster) and click Add volume (it shows the preset's size, which the template already sets) — that's where your models and films live.

  2. 2

    Set a password

    Under Set overrides, change STUDIO_PASSWORD from change-me to your own. If you forget, a random one is saved on the pod: open Connect → Web Terminal and run cat /workspace/studio/PASSWORD.txt, or use Edit Pod to set one.

  3. 3

    Open your studio

    First boot downloads ~139 GB of models in the background — images are ready in about 3 minutes and everything in about 6–18 minutes, measured on a real RTX 4090.

FAQ

Which GPU should I pick?

The RTX 4090 (24 GB) is the default and handles the full stack comfortably. A 5090 or L40S will generate faster if you don't mind paying more per hour.

Is my data private?

Yes. Everything — models, projects, generated media — lives on your pod's own persistent volume. Nothing is sent to a third-party API unless you optionally enable an LLM key for script breakdown.

What happens if I stop or terminate the pod?

Stopping the pod keeps the volume intact (you keep paying for storage, not compute). Terminating the pod deletes the volume — and everything on it — permanently.

What's the content policy?

The open models used here are not filtered beyond what upstream ships. The studio adds exactly one hard, non-optional block: sexual content involving minors is always rejected, with no setting to turn it off.
