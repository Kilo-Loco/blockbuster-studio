Blockbuster Studio is an AI film studio that runs on a single GPU you rent from [Runpod](https://www.runpod.io). You deploy it with one click, open it in your browser, and use it to:

- **Create** images and short video clips from a text prompt or a reference image.
- **Edit** images, render the same subject from new camera angles, and turn a recording of yourself into a character's performance.
- **Make a film**: paste an idea or a script, and the studio breaks it into scenes and shots, draws each frame with the same characters and locations, animates the shots, and exports one MP4. For films where the camera moves and cuts need to be exact, you can block the scene out first — see [Make a film with a previs](/guides/previs).

Video clips render with sound by default (the studio's default video engine is **LTX-2.5**). **MiniMax H3** is available as an alternative engine with different strengths and its own license terms — see [Create images and video](/guides/create#if-your-pod-uses-a-different-video-engine).

Everything runs on your own pod. There are no subscriptions and no per-generation fees (an optional AI provider for script breakdown bills you separately), and your models, projects and media stay on your pod's storage.

## What you need

- A **Runpod account** with credit on it. You pay Runpod directly for the GPU and storage.
- A browser. The studio works in any modern browser.
- A free **Hugging Face account**, for the video model's download token.
- Optional: an **Anthropic or OpenAI-compatible API key**, set as a pod variable, if you want the AI to break scripts into scenes and shots for you. See [Settings and API keys](/manage/settings).

Using Blender for a previs, or an AI agent? See [What you need](/requirements) for the full list.

## What it costs

The recommended GPU, an RTX PRO 4500, costs about **$0.72/hour** on Runpod's Secure Cloud. Prices change, so check the Runpod console before you deploy.

You pay for the GPU while the pod is running and for storage while it exists. [Stop the pod](/manage/stop-and-back-up) when you're not using it.
